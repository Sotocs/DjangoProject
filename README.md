
# DjangoProject

Django‑проект для интернет‑магазина (каталог товаров). В проекте реализована базовая структура приложения `catalog`, настроены миграции, управление зависимостями организовано через Poetry.

## Особенности проекта

- **Стек технологий**: Python, Django, Poetry.
- **Архитектура**: модульная структура с вынесением конфигурации в папку `config`.
- **Управление зависимостями**: используется `pyproject.toml` и `poetry.lock` для воспроизводимости окружения.
- **Миграции**: подготовлены и применены для моделей товаров и категорий.
- **Контроль версий**: виртуальное окружение (`.venv`) исключено из репозитория через `.gitignore`.

## Требования

- Python 3.9 или выше.
- Установленный Poetry для управления зависимостями.

## Установка и запуск

### 1. Клонирование репозитория

```
git clone <URL-репозитория>
cd DjangoProject
```
### 2. Установка зависимостей
Проект использует Poetry, поэтому зависимости устанавливаются одной командой:

poetry install
Эта команда создаст изолированное виртуальное окружение и установит все необходимые пакеты согласно pyproject.toml.

### 3. Настройка переменных окружения
Скопируйте шаблон файла переменных окружения:

cp .env.sample .env
Заполните файл .env необходимыми значениями (например, DEBUG, SECRET_KEY, параметры базы данных).
Важно: файл .env не должен попадать в репозиторий — он уже исключён через .gitignore.

### 4. Применение миграций
Перед запуском сервера необходимо создать таблицы в базе данных:


poetry run python manage.py migrate
### 5. Создание суперпользователя (опционально)
Для доступа к админ‑панели Django создайте суперпользователя:


poetry run python manage.py createsuperuser
Следуйте инструкциям в терминале для ввода логина, email и пароля.

### 6. Запуск сервера разработки
Запустите сервер командой:


poetry run python manage.py runserver
Проект будет доступен по адресу http://127.0.0.1:8000/, админ‑панель — по адресу http://127.0.0.1:8000/admin/.

Структура проекта
catalog/ — приложение Django для работы с товарами и категориями.
config/ — настройки проекта (включая settings.py, urls.py и другие конфигурационные файлы).
.venv/ — виртуальное окружение (игнорируется Git, не хранится в репозитории).
manage.py — точка входа для команд Django.
poetry.lock, pyproject.toml — файлы для управления зависимостями.
.gitignore — правила игнорирования файлов.
.env.sample — пример файла переменных окружения.
Работа с миграциями
Все миграции для приложения catalog уже подготовлены и применены. При добавлении новых моделей или изменении существующих используйте следующие команды:

bash
poetry run python manage.py makemigrations
poetry run python manage.py migrate
